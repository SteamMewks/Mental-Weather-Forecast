# 心の天気予報 / Mental Weather Forecast

毎日の気分や疲労を「天気」のように記録して、あとからゆるく振り返るためのブラウザアプリです。

その日の気分、疲労、朝の調子、短いメモをカレンダーへ残し、直近1週間の傾向を確認できます。

記録は基本的に端末内へ保存されます。

## 主な機能

- 5段階の気分記録
- 3段階の疲労記録
- 「朝、気分良く起きれた？」の記録
- 15文字までの短いメモ
- 月ごとのカレンダー表示
- 直近1週間の平均気分・平均疲労の表示
- 今日の状態に応じた短いメッセージ
- 1日1回の「明日の運試し」
- JSON / CSV形式での記録書き出し
- PWA対応
  - 対応環境ではホーム画面へ追加し、アプリのように利用できます
  - 起動時などに更新を確認します
- 『夢幻ノ迷宮』との連動機能

## 使い方

1. カレンダーから記録したい日を選びます。
2. 気分、疲労、朝の状態、必要ならメモを入力します。
3. 「保存」を押すと、その日の記録がカレンダーへ反映されます。
4. 画面下部では、直近1週間の記録をもとにした簡単な傾向を確認できます。

詳しい使い方はこちら：

https://note.com/steammewks/n/nc8cbbf9b66f9

## データについて

記録データはブラウザの `localStorage` に保存されます。

保存対象となる記録は直近1年分です。古い記録は保持期間を過ぎると削除されます。

必要な記録は「ダウンロード」から期間を指定し、以下の形式で書き出せます。

- JSON
- CSV

端末の変更、ブラウザデータの削除、ストレージの初期化などによって記録が失われる場合があります。残しておきたい記録は定期的に書き出してください。

## PWAとして使う

対応ブラウザでは、本アプリを端末へインストールしてホーム画面から起動できます。

アプリ内の

`⚙ ダウンロード` → `📲 アプリとしてインストール`

から操作できます。

iPhone / iPadなど、一部環境ではブラウザの共有メニューから「ホーム画面に追加」を選択してください。

## 『夢幻ノ迷宮』との連動

「連動設定」でユーザー名を設定すると、日付とユーザー名をもとに連動用の符号が生成されます。

この機能はSteamMewks制作の『夢幻ノ迷宮』との連動を目的としています。

連動内容については、ゲーム内および関連コンテンツで案内します。

## このアプリについて

「心の天気予報」は、日々の状態を大げさに評価するのではなく、

**今日は晴れだった。今日は少し曇っていた。**

そんな感覚で、自分の状態を振り返るための小さな記録ツールです。

表示される分析やメッセージは、入力された記録をもとにした簡易的なものです。医療上の診断、治療、専門的な助言を目的としたものではありません。

心身の状態について強い不安がある場合や、生活に支障が出ている場合は、必要に応じて医療機関や専門家へ相談してください。

## 動作環境

HTML / CSS / JavaScriptのみで動作するブラウザアプリです。

PWAとして利用する場合は、Service WorkerおよびWeb App Manifestに対応したブラウザが必要です。
